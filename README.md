# AlimentaV.E.S.

Plataforma digital para conectar donantes de alimentos con comedores populares de Villa El Salvador.

## Problema
Los excedentes de alimentos aprovechables pueden desperdiciarse mientras organizaciones comunitarias necesitan recursos para atender a sus beneficiarios.

## Solución
AlimentaV.E.S. facilita la publicación, consulta y solicitud de donaciones alimentarias.

## Objetivo de Desarrollo Sostenible
ODS 2: Hambre cero.

## Funcionalidades
- Publicación de donaciones.
- Catálogo de alimentos disponibles.
- Solicitud de donaciones.
- Seguimiento de estados.
- Panel de estadísticas.
